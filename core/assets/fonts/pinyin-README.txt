Pinyin glyph fallback: a subset of Noto Sans Regular.
Source: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
License: SIL Open Font License 1.1 (see pinyin-OFL.txt).

Contains ASCII and the upper/lowercase marked pinyin vowels, including Latin
Extended-B characters missing from font.woff. Used as a fallback for both
regular HUD text and outlined world text so third tones and marked u-umlaut
remain legible. The original Chinese font remains in use for Chinese glyphs.
